# Godot Telegram Agent

A Telegram-controlled Godot game development agent.

## Goals
- Receive commands from Telegram.
- Generate and review GDScript.
- Run real Godot tests.
- Build Android APK with GitHub Actions.
- Report results and build logs.

## Security
- Never commit API keys or bot tokens.
- Allow commands only from the authorized Telegram user.
- Keep backups before modifying project files.
